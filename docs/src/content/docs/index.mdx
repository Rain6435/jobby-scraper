	<Card title="Unfiltered pool" icon="list-format">
		Every currently listed posting is stored, with no keyword, title, location or age filtering.
		Consumer apps do their own matching downstream.
	</Card>
	<Card title="Full-replace snapshots" icon="random">
		Each run writes exactly what is live right now. A job leaves the pool once its company stops
		listing it.
	</Card>
	<Card title="40+ boards" icon="puzzle">
		Workday, Greenhouse, Ashby, Lever, SmartRecruiters, SuccessFactors, Oracle Cloud and many more,
		plus custom portals like Google, Apple and Microsoft.
	</Card>
	<Card title="Any SQL database" icon="seti:db">
		Writes to any SQLAlchemy URL: SQLite, PostgreSQL, MySQL. Normalized tables for companies,
		jobs, locations and GeoNames towns.
	</Card>
