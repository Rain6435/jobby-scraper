All configuration lives in [`config.json`](https://github.com/Rain6435/jobby-scraper/blob/main/config.json) at the repo root. Types for every entry are declared in [`scraper/config_types.py`](https://github.com/Rain6435/jobby-scraper/blob/main/scraper/config_types.py).

```json
{
  "criteria": {
    "keywords": ["developer", "data analyst", "stagiaire", "..."],
    "blacklist_keywords": ["senior", "manager", "directeur", "..."]
  },
  "companies": [
    {
      "name": "CAE",
      "board": "workday",
      "url": "https://cae.wd3.myworkdayjobs.com/wday/cxs/cae/career/jobs",
      "careers_base": "https://cae.wd3.myworkdayjobs.com/en-US/career",
      "blurb": "…",
      "logo": "data/logos/cae.svg"
    }
  ]
}
```

## `companies`

A list of company entries. Order matters only for sharding (shards are filled in list order).

### Fields on every entry

| Field | Required | Description |
| ----- | -------- | ----------- |
| `name` | yes | Display name. Stored in `companies.name`, matched by `--company`, and slugified into every job id prefix. Must be unique. Changing it changes every job id for the company. |
| `board` | yes | Which scraper to use. See [Supported boards](/jobby-scraper/reference/boards/). An unknown value is logged and the company is skipped. |
| `blurb` | no | Short company description, copied to `companies.blurb`. Generated by `scraper.backfill_blurbs` or written by hand. |
| `logo` | no | Relative path to the company's SVG logo, copied to `companies.logo`. |
| `default_country` | no | ISO 3166-1 alpha-2 code used as the country only when a location string has no country signal of its own. For confirmed single-country employers only. |

### Board-specific fields

Each board reads its own extra fields: `token` for Greenhouse, `slug` for Ashby, `url` and `careers_base` for Workday, and so on. They are listed per board in [Supported boards](/jobby-scraper/reference/boards/).

## `criteria`

`keywords` and `blacklist_keywords` are reference lists of English and French early-career terms and seniority words. **The pipeline does not use them.** They are kept for consumer apps that want a ready-made keyword bank for their own filtering.
